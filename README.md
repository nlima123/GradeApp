# GradeApp

An Android application built with Kotlin that helps students calculate and track their GPA and individual course grades.

## Overview

GradeApp was developed as an independent project for a Database Applications course. The application is designed to help high school and college students organize their courses, enter grades, and calculate their GPA.

The project also considers graduation requirements to help students better understand their academic progress.

## Features

* Calculate overall GPA
* Calculate individual course grades
* Track courses and grades
* Account for course credit hours
* Support academic and graduation requirement tracking
* Simple and intuitive Android interface

## Technologies

* Kotlin
* Android Studio
* Android SDK
* Gradle

## Target Users

The application is primarily designed for:

* High school students
* College students
* Academic advisors
* Parents helping students track academic progress

## Getting Started

### Prerequisites

* Android Studio
* Android SDK
* Kotlin
* Android device or emulator

### Installation

1. Clone the repository:

```bash
git clone https://github.com/nlima123/GradeApp.git
```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Run the application using an Android emulator or connected Android device.

## Project Purpose

This project was created to apply software development concepts to a practical academic application while developing experience with Android development, Kotlin, application logic, and data management.
